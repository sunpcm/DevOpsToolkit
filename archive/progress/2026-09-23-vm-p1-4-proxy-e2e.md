## 网络边界与可重复命令

此前 VM 直连 `download.docker.com` 被重置。本轮先在严格命名的一次性 22.04 诊断 VM 中，
用宿主机现有代理测试 Docker 官方 GPG URL，收到 HTTP 200；诊断 VM 随即删除。
完整测试只在一次性 VM 中配置测试代理，不放宽 Docker GPG 校验或生产主机配置：

```bash
MULTIPASS_TEST_PROXY=http://192.168.252.1:7897 \
ANSIBLE_COLLECTIONS_PATH=<经 lock 校验的隔离目录>/collections \
uv run --with ansible-core==2.21.4 \
  ./tests/multipass-smoke.sh run --with-faults --report <隔离目录>/vm-report-proxy.txt
```

`192.168.252.1` 是本机这次 Multipass 共享网络的网关，不是通用常量；重跑前必须在当前宿主机
重新确认 VM 网关及代理访问范围。只读 `netstat` 在本轮显示宿主机代理监听 `*.7897`；
这可能允许其他可达网络设备使用该代理，需独立检查宿主机防火墙并按实际使用场景限制访问，
但本轮没有修改宿主机代理或防火墙。
